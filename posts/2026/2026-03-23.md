---
title: "About How We're Not There Yet"
date: 2026-03-23
excerpt: ‘AI’ hype is still, seemingly, just that.
---
<span class="dropcap">E</span>very time I log in to LinkedIn or browse YouTube, there is another post about a wonderful workflow/use case for the large language models and machine learning tools that everyone collectively calls ‘AI’. And I am always skeptical. Today demonstrates why.

I had a very simple use case. Last week I ran a survey for my co-workers. The survey presented each respondent 10 different emoji. For each emoji, I requested they use one word to describe what they thought the emoji would mean if used in a health/medical context. The survey was run using Qualtrics. Once the responses were collected, I exported the data as a CSV file. From that data I wanted a set of pie charts visualizing the count of responses received for each emoji in the survey. With everything that ‘AI’ can supposedly do for us these days, this seemed like a reasonable request.

Since the data was in a CSV file, the first thing I did was open the file in Excel. My first task was to normalize the responses. The biggest variation in the responses was capitalization, so, using Copilot (our organization has a subscription), I asked to have the text in all the cells converted to lower case. Copilot could not do this because my file was a CSV and not in XLSX format. So I saved the file in the new format and repeated my request. This time, Copilot said it couldn't change the text to lowercase, but it could show me a formula to use to convert the case. Fail numberr 1. I closed the file, opened it in BBEdit (I'm on a Mac), selected all the text, and performed the case change with one command.

Next I went back into Excel and asked Copilot to analyze my data and create pie charts showing the breakdown of responses. However, Copilot kept treating my data as one large chunk instead of 10 individual data sets. Fail number 2.

Copilot is also <em>sluggish</em>. So I copied my CSV data, pasted it into Gemini, and asked it to create pie charts for each of the 10 response sets. To its credit, Gemini very quickly did so. I had 10 pie charts showing the breakdown of responses for each emoji. However, the charts were a little messy. I wanted to paste them into Affinity so I could clean them up and export them as PDF for a presentation. The charts Gemini created were all PNGs, making them difficult to edit. So I asked Gemini to recreate the pie charts as SVG files. And it gave me another set of PNG files. So I asked it if it could provide SVG code to download that I could open in Affinity. This time, it provided code for 10 charts in SVG code, but the charts were all wrong. The first 2 charts were accurate but the remainder of the charts were made up -- no connection to my original data. I pointed this out to Gemini and it apologized and said it would try another method for creating the pie charts. It created two charts as a sample. These charts looked good, so I asked it to create the remaining charts. The remaining 8 charts were a complete mess. Not only were they -- again -- made up and not based on my data, but they were also distorted. The pie charts were not circular but more like broken ovals.

Fail number 3. So I gave up on Gemini.

I went back into Excel and tried a few different prompts with Copilot. This time, I was able to craft the correct incantation that would get Copilot to treat my data as 10 individual datasets. It created the necessary pivot tables and pie charts for representing my data. The charts themselves were -- from a design perspective -- trash, but it’s Excel. It was enough to be able to copy-and-paste them into Affinity and edit them from there into something approximating a professional report.

Overall, this was not a positive experience. Did I save myself any time or frustration by using machine learning tools over simply performing operations myself in Excel? I'm not sure, but I kinda doubt it. The world is unrelenting in its work to try an convince me that ‘AI’ is going to change the way we do things, but my experience regularly comes up well short of the promise.

Supposedly it’s getting better all the time. But better at what? The companies that produce these tools have a single incentive: revenue. That incentive will not necessarily drive the tools to be ‘better’. Or, perhaps it’s more accurate to say that my definition of better might be quite different from an ‘AI’ company’s definition of better because our goals are fundamentally different. That’s not necessarily a problem, but it is something to keep in mind.
